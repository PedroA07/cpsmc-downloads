# Sistema Interno CPSMC — downloads

Repositório público de **distribuição** do Sistema Interno da CPSMC
(Caixa de Previdência dos Servidores Municipais de Cubatão).

Aqui ficam apenas os instaladores publicados automaticamente pelo CI.
O código-fonte é mantido em repositório privado.

- **Baixar:** veja a página de download ou a versão mais recente em *Releases*.
- **Atualizações:** o aplicativo se atualiza sozinho a partir destas releases.

Dúvidas: departamento de Processamento de Dados.
